| 1 | フロントTOP（ポータル画面）⇒社宅TOP⇒社宅戸別予約を選択する | 社宅戸別予約検索画面が画面項目仕様どおりに初期表示されること |

| 5 | 検索結果から「入居申込管理番号」を選択する | 選択した対象の社宅戸別予約処理画面が表示されること |

| 11 | 「新規登録」を押下する | 社宅戸別予約処理画面へ遷移すること |
| 12 | 「新規登録」から社宅戸別予約処理画面へ遷移する | 「氏名コード」が入力可能で、その他の入力項目が非活性であること |
| 13 | 「新規登録」から遷移した直後の画面を確認する | 「表示」が活性、「登録」「クリア」が非活性、「社宅情報」が非表示であること |

| 15 | 「表示」後の社員情報を確認する | 会社コード、会社名、組織コード、組織名、出向先会社、社員帰属、社員状態等が対象社員の情報に基づいて表示されること |
| 16 | 「表示」後の入居申込情報を確認する | 入居理由、申込理由、申込理由年月日、職場最寄駅、勤務先電話番号、希望記入欄、住居種別、家賃等が入居申込情報に基づいて表示されること |
| 17 | 管理主任事務所コードが1001または2001で、社員状態コードが「05」（役員）の社員を表示する | 「厚生1(承認者)メールアドレス」が空欄で表示されること |
| 18 | 管理主任事務所コードが1001または2001で、社員状態コードが「08」（退職者）の社員を表示する | 「厚生1(承認者)メールアドレス」が空欄で表示されること |
| 19 | 在籍出向Aの社員を表示する | 出向先会社の社宅通知用メールアドレスが「厚生1(承認者)メールアドレス」に表示されること |
